# Практическая работа №12
## Кейс 1. Меню для кофейни

### Основной продукт:
1. Капучино — 150 руб.
2. Латте — 170 руб.
3. Американо — 120 руб.
4. Флэт уайт — 180 руб.
5. Эспрессо — 100 руб.
### Расширенный функционал:
1. Капучино: эспрессо + молоко (250 мл / 350 мл)
2. Латте: много молока + эспрессо (350 мл / 450 мл)
3. Американо: эспрессо + вода (200 мл)
4. Флэт уайт: двойной эспрессо + молоко (250 мл)
5. Эспрессо: концентрированный кофе (30 мл)
